# 🏅 2024 Paris Olympics Data Analysis

This project presents a data-driven analysis of the 2024 Paris Olympics using Power BI and datasets sourced from Kaggle. It offers interactive dashboards that provide valuable insights into country-wise performance, athlete participation, medal distribution, and gender-based trends.

## 📌 Objective
To explore, analyze, and visualize the 2024 Paris Olympics data in an interactive and insightful way using Power BI.

## 📊 Key Features
- Country-wise medal tally analysis   
- Gender-based participation trends  
- Athlete-wise achievements   
- Clean and interactive Power BI dashboard  

## 🛠 Tools & Technologies Used
- **Power BI** – For building interactive dashboards  
- **Kaggle** – Data source  
- **Excel – For preprocessing and data cleaning

## 📥 How to Use
1. Download the `.pbix` file from the `/powerbi` folder.
2. Open it in Power BI Desktop.
3. Explore the interactive dashboard and filters.
4. (Optional) Modify visuals or update data as needed.
